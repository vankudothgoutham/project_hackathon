# Cloud-Native Full-Stack Hackathon App 🚀

A scalable, full-stack web application built with a modular architecture, featuring decoupled frontend and backend services, structured infrastructure setup, and automated CI/CD deployment pipelines.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** React.js, HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js, RESTful APIs
- **Cloud & DevOps:** AWS, Docker, GitHub Actions (CI/CD)
- **Tooling:** npm, Git, VS Code

---
